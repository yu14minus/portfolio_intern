# Portfolio Website

自身の制作実績やスキルセットをまとめたポートフォリオサイト。

## 公開URL

https://yu14minus.github.io/portfolio_intern

## 概要

サークル活動や個人開発で制作したWebサイト、Webアプリケーション、動画等の実績を掲載しているポートフォリオサイト。  
各制作物の画面プレビュー、使用技術、GitHubのソースコードへのリンク等を掲載。

## 使用技術

- HTML
- CSS
- JavaScript
- GitHub Actions

## 実装のポイント

- **レスポンシブ対応**: スマートフォンおよびPC双方で崩れず閲覧できるレイアウト
- **シンプルなUI設計**: 閲覧を妨げない適度なアニメーションやスライドショーを取り入れ、視認性と使いやすさを重視した構成
- **CI/CDによる自動化**: GitHub Actionsを活用し、mainブランチへのプッシュ時に最新コミット日を自動置換した上でGitHub Pagesへデプロイするワークフローを構築
